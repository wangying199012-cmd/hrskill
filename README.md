# hr-query Skill

德创数字人事库查询 Claude Code Skill。

## 触发场景

当用户询问德创公司的员工信息、部门信息、人事信息时自动触发，例如：
- 「营销中心有几个人」
- 「查一下智能装备部」
- 「德创有多少员工」
- 「某部门有哪些人」
- 「某人是哪个部门的」
- 「德创人事库」
- 「6月份合同到期的有几人」

## 文件路径

**默认文件**：`D:\claude code\德创数字花名册20260522.csv`（24列完整版）

用户可通过绝对路径指定其他文件。

## 文件编码

CSV 文件编码为 GB18030（简体中文 Windows 编码）。读取时必须先转换为 UTF-8。

## 查询方法

### 按部门查询
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep "部门名称"
```

### 按姓名查询
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep "姓名"
```

### 按板块/备注查询（如智能装备板块）
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep "智能装备板块"
```

### 统计人数
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep -c "关键词"
```

### 计算月度薪资总额
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep "关键词" | awk -F',' '{sum += $7} END {print sum}'
```

### 查询合同到期（如2026年6月）
```bash
iconv -f GB18030 -t UTF-8 "<file_path>" 2>/dev/null | grep ",2026/6/"
```

## 输出格式

### 人数统计
返回人数和名单表格：
```
**营销中心共 15 人：**

| 序号 | 姓名 | 二级部门 | 岗位 | 月薪 |
|------|------|----------|------|------|
| 8 | 席喜峰 | 质量交付部 | 副主任 | 16,760 |
...
```

### 薪资统计
返回人数、月度薪资总额、年度薪资总额（13薪）。

### 合同到期查询
返回合同到期人员名单，包含合同到期日期。

## 可视化报告

当查询结果人数≥10人或用户要求图形化输出时，自动生成 HTML 或 PNG 可视化报告：
- HTML 报告：包含 ECharts 交互图表，深色主题
- PNG 图片：饼图+柱状图组合，适合直接发送

## 安装使用

将此 skill 放入 Claude Code 的 `~/.claude/skills/hr-query/` 目录即可使用。

## 工作流程

1. 识别查询意图（查人数、查人员、查部门、查薪资、查合同等）
2. 确定搜索关键词
3. 用 iconv 读取 CSV 文件（GB18030 → UTF-8）
4. 用 grep 过滤相关行
5. 必要时用 awk 计算薪资总额
6. 返回格式化结果
7. 必要时生成可视化报告
